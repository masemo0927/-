# 세종시설관리공단 보고서 자동화 시스템

브라우저에서 내용을 입력하면 **한글(hwpx) 파일을 즉시 생성**하여 다운로드할 수 있는 Flask 기반 웹 애플리케이션입니다.

---

## 지원 보고서 종류

| 탭 | 보고서 종류 | 주요 입력 항목 |
|----|------------|---------------|
| 1  | 검토 보고   | 제목, 날짜, 팀명, 담당자, 전화, 검토배경, 검토결과 항목(동적 추가), 결론 |
| 2  | 계획 보고   | 제목, 날짜, 팀명, 담당자, 전화, 목적, 기간, 대상, 내용, 예산, 향후일정 |
| 3  | 현장점검 보고 | 제목, 날짜, 팀명, 담당자, 전화, 점검일시, 점검장소, 점검결과, 조치사항 |
| 4  | 세미나/행사 개최 계획 | 제목, 날짜, 팀명, 담당자, 전화, 행사명, 일시, 장소, 주요내용, 예산 |

---

## 실행 방법

### 요구사항

- Python 3.8 이상

### 1단계: 의존성 설치

```bash
pip install flask
```

또는

```bash
pip install -r requirements.txt
```

> **참고:** `app.py`를 직접 실행할 경우 Flask가 설치되어 있지 않으면 **자동으로 설치**합니다.

### 2단계: 서버 실행

```bash
python app.py
```

### 3단계: 브라우저 접속

```
http://localhost:5000
```

---

## 사용 방법

1. 브라우저에서 `http://localhost:5000` 접속
2. 상단 탭에서 **보고서 종류** 선택
3. 양식을 작성 (줄바꿈으로 세부 항목 구분)
4. **"HWPX 생성 및 다운로드"** 버튼 클릭
5. `YYYYMMDD_보고서종류_제목.hwpx` 파일이 자동 다운로드

## HWPX 서식 규격

| 항목 | 값 |
|------|----|
| 용지 | A4 (210 × 297mm) |
| 좌우 여백 | 56.7mm |
| 상하 여백 | 42.5mm |
| 머리말 | 28.3mm |

### 글꼴 구성

| 용도 | 글꼴 | 크기 |
|------|------|------|
| 보고서 제목 | HY헤드라인M | 22pt |
| 소제목 (□) | HY헤드라인M | 16pt |
| 본문 (○ / -) | 휴먼명조 | 15pt |
| 날짜/담당자 | 함초롬돋움 | 10pt |
| 표 셀 | 맑은 고딕 | 12pt |
| 붙임/끝. | 휴먼명조 | 15pt |
